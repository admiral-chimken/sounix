# ◉ SOUNIX

## Linux Personal Assistant

Sounix is a personal Linux assistant built with Python.

It provides a simple interface for system tools, security controls, file management, and automation.

---

# Features

## System
- System information
- Distribution detection
- System health checks
- Power controls

## Security
- Firewall status
- Enable/disable firewall
- VPN status
- Tailscale support
- Network scanning tools

## Assistant
- Memory system
- Calculator
- Google search
- Voice support
- Natural commands

## File Management
- Browse files
- Create folders
- Copy files
- Move files
- Rename files
- Delete files

---

# Installation

## Requirements

- Linux
- Python 3
- Git

---

## Install Sounix


# Download & Installation

## 1. Clone the repository

```bash
git clone https://github.com/admiral-chimken/sounix.git
```

## 2. Enter the project folder

```bash
cd sounix
```

## 3. Run the installer

```bash
./install.sh
```

## 4. Start Sounix

```bash
./sounix
```
