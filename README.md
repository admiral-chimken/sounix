# Sounix

## Linux Personal Assistant

Sounix is a Python-based Linux assistant designed to help manage your system through commands and a graphical interface.

## Features

✅ System information  
✅ Security dashboard  
✅ Firewall status  
✅ VPN status  
✅ Tailscale support  
✅ File management  
✅ Memory system  
✅ Calculator  
✅ Google search  
✅ Package manager support  
✅ GUI interface  
✅ Auto-start support  

## Supported Systems

Currently developed on:

- Arch Linux

Planned support:

- Kali Linux
- Debian
- Ubuntu
- Fedora
